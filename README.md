Final-year computer science student at RV University, Bangalore, working in machine learning: computer vision, applied language research, and systems that run on local hardware.

Most of my work starts as a question I can only answer by building the thing and watching where it breaks. My site states only what my files back up, and each project says how far it actually got.

<br>

### Selected work

| Project | What it is |
|:--|:--|
| **[Live3D](https://adithyanmurthy.com/work/live3d)** | Phone, drone or CCTV video turned into a 3D model of the space, live in the browser, then refined into real meters you can measure. Runs on one Apple Silicon workstation, no cloud. |
| **[LawVerse](https://adithyanmurthy.com/work/lawverse)** | Legal NLP over 231,908 court judgments. Our first pipeline said 22 of 25 legal concepts had changed meaning; after we found and fixed four silent defects in it, one had. |
| **[One Camera Brain](https://adithyanmurthy.com/work/one-camera-brain)** | Theft, safety and work-insight rules on cameras a site already owns, with evidence clips sealed so tampering shows. |
| **[AI E](https://adithyanmurthy.com/work/ai-employees)** | Five role-specific AI agents on one runtime. The model only drafts; deterministic engines check the numbers before an answer is certified. |
| **[PAMO](https://adithyanmurthy.com/work/pamo)** | A macOS guardrail between me and terminal AI coding agents. In three weeks of logged use: 3,699 decisions, 258 held for a human. |
| **[Trajectory prediction](https://adithyanmurthy.com/work/trajectory-prediction)** | LSTM what-if forecasting on nuScenes: how nearby road users respond if the car carries on, brakes or accelerates. |
| **[Textegrity](https://adithyanmurthy.com/work/textegrity)** | An eight-detector ensemble for AI-written text, with a stage that tests how easily detection breaks: 97.86% in distribution, 55.7% on outside text. |
| **[CreeperX mainboard](https://adithyanmurthy.com/work/creeperx)** | A four-layer controller board for a 12-servo quadruped: 142 components, three independent 5 A power rails. |

All 22 projects, with what is finished and what is not: **[adithyanmurthy.com/work](https://adithyanmurthy.com/work)**
